3D Hero (short)

  • Hero = presentation of the shared Web AI workspace — not backend authority.
  • Seats around the ring = participants; center = shared workspace.
  • Inspection spine = guided visual stages; “authorization” stage does not grant permission.
  • Turn lifecycle = visual only; not a live provider call.

Seats & keys (short)

  • Login = Firebase. API keys = server (seat or platform).
  • probeMode: stub = free smoke, no provider billing.
  • TEAMAI_SEAT_SECRET_KEY = encrypts seat keys; not an OpenAI key.
