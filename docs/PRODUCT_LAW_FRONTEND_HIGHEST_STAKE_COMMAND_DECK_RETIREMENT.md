# Product Law Reconciliation — Command Deck Retirement

The historical Command Deck is retired as a current product and deployment surface.

Active product path:

`Entrance → 3D World → Authentication → Restored Authorized State → 3D Configuration/Settings → Center Workspace → Turn / Evidence`

The `/spatial/` route is not a current product route. Historical `frontend/spatial/**` source, contracts, tests, and commits remain available as evidence/reconstruction material only.

Existing prototype animations, camera paths, effects, ambience, and timing values remain replaceable implementation baselines and must not constrain the final adaptive expansion or semantic electrical turn-loop architecture.
