# Machine Hero frontend preview

Status: TEMPO / FRONTEND EVIDENCE

The opt-in preview is enabled by `?machine-preview` and remains separate from the production Hero canvas.

## Current proof surface

- A canonical transition is built from semantic source/target divisions.
- Geometry is represented as explicit machine parts.
- The subject footprint is derived from those parts.
- The camera keeps a named identity while its target comes from the derived subject.
- Moving target geometry moves the derived subject and therefore the camera target.
- The same transition builder accepts the valid reverse Seat-1 pair without a renderer-specific branch.

## Deliberate limits

- no production replacement of the existing canvas;
- no second production camera authority;
- no additional production branch activation;
- no final 3D visual, animation, electrical, C8, C9, or C10 claim.

## Promotion mapping

This contributes evidence toward M1, M2, M3, M4, and part of M5. M6 still requires assembled-browser proof, and no implementation is promoted until all M1-M6 gates are reproducibly satisfied and governed.
