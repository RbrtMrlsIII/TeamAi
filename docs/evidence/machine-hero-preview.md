# Machine Hero frontend preview

Status: TEMPO / FRONTEND EVIDENCE

The opt-in preview is enabled by `?machine-preview` and is intentionally separate from the production Hero canvas.

## What it proves

- A canonical transition is built from semantic source/target divisions.
- Geometry is represented as explicit machine parts.
- The subject footprint is derived from those parts.
- The camera keeps a named identity (`SEAT_CLOSE`) while its target comes from the derived subject.
- Moving the target geometry moves the derived subject and therefore the camera target.

## What it does not prove

- It is not the production renderer.
- It does not activate a second production branch pair.
- It does not establish final 3D visual identity, animation, electrical topology, or C8/C9/C10 completion.

## Promotion

This evidence may contribute to M1, M2, M4, and part of M5, but it cannot satisfy the governed promotion rule without the complete M1-M6 matrix and an explicit project decision.
