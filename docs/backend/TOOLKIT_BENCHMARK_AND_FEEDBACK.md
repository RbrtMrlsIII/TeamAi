# ToolKit Benchmark & Feedback

## Benchmark goal

Use TeamAi as a consuming project to test whether the Universal AGENT ToolKit prevents real failure modes across different fields and project types.

## Current generalized lesson candidate

A technology can be labeled legacy and still be dangerous when repository structure makes its implementation path easy to rediscover. A stronger universal safeguard is explicit retirement plus active-surface deletion plus automated detection plus continuity documentation.

## What remains TeamAi-specific

Firebase/Firestore authority, PayPal promotion terms, Firebase UID correlation, provider choices, Web AI product behavior, and TeamAi domain/schema decisions remain TeamAi-owned.

## Promotion rule

Do not copy TeamAi findings verbatim into ToolKit. Validate first, generalize second, then promote through the ToolKit knowledge/skill lifecycle. ToolKit changes do not automatically flow back into TeamAi.
