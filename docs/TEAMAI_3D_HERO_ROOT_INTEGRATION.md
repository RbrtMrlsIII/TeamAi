# TeamAi 3D Hero — Cross-Root Integration Contract

Status: planning/continuity knowledge. Active TEAM-EXPERIENCE-029 implementation remains gated by `MASTERPLAN.md`.

## Purpose

The 3D Hero must consume the existing frontend roots and bounded spatial skills instead of inventing parallel theme, motion, animation, transition, responsive, or accessibility authorities.

## Root/skill ownership

| Concern | Authority | 3D Hero interpretation |
|---|---|---|
| Theme/root architecture | canonical unified theme root + Spatial coordinator | semantic mode, surfaces, focus, signal, status, atmosphere/material/light parameters |
| Motion/timing | `skills/frontend/spatial/motion/SKILL.md` | shared duration/easing/delay vocabulary; reduced-motion mapping |
| State transitions | `skills/frontend/spatial/transition/SKILL.md` | semantic state-pair transitions for focus/active/contribute/absorb/handoff |
| Choreography | `skills/frontend/spatial/animation/SKILL.md` | product-purpose sequences only; no parallel animation framework |
| Responsive | `skills/frontend/spatial/responsive/SKILL.md` | framing, density, touch/pointer adaptations; preserve world semantics |
| Accessibility | `skills/frontend/spatial/accessibility/SKILL.md` | non-color status, reduced motion, keyboard/precision handoff, readable fallback |
| Spatial composition | `skills/frontend/spatial/UI_UX-Promax-Skill.md` | coordinates these concerns without absorbing their ownership |

## Integration rule

`canonical root → bounded skill vocabulary → spatial adapter → renderer`

The renderer may interpret shared semantics as light, material, camera, motion, and responsive behavior. It may not create a competing source of truth.

## Light-skeomorphic first mode

Light mode uses physically motivated environmental illumination, manufactured material response, contact/depth separation, restrained semantic contribution light, and grazing/rim response. Dark-glassmorphism remains a paired future interpretation of the same semantic inputs.

## Motion model

Animation owns choreography, Transition owns state pairs, Motion owns timing tokens. A Hero lifecycle animation must therefore be expressed as semantic state transitions consuming shared Motion tokens; it must not embed one-off durations/easing or create a parallel animation runtime.

## Responsive model

Responsive adaptation changes framing, density, effect budget, and interaction affordances—not product meaning. The same shared workspace remains central and Seats remain distinct. 1–8 Seat scaling remains deterministic.

## Accessibility model

Visual light/status cues must have non-color equivalents. Reduced motion suppresses continuous drift and nonessential choreography while preserving semantic state. Precision configuration, evidence review, and text-heavy work hand off to normal UI.

## Verification

Each future 3D slice must record which root/skill vocabulary it consumes, the semantic inputs it maps, the reduced-motion behavior, responsive behavior, and browser evidence. A visual pass does not replace contract verification or endorsement.
