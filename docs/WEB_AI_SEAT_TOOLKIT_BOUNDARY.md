# WebAi Seat ↔ Universal ToolKit Boundary

## Purpose

TeamAi consumes the Universal AGENT ToolKit as reusable seat equipment and operating discipline. ToolKit supplies generalized process skills, workspace governance, continuity, verification, knowledge discipline, project/field adaptation, and scale adaptation. TeamAi remains authoritative for TeamAi-specific product and domain behavior.

## Responsibility model

A WebAi seat is modeled as:

```text
responsibility boundary
+ applicable skill bundle
+ workspace governance
+ project adaptation
+ current Agent capacity
```

Agent count is therefore a resource-allocation variable, not a reason to duplicate the universal skill library. With fewer Agents, an Agent may carry several responsibility units. With more Agents, the same units may be partitioned across Agents while preserving the underlying skill definitions.

The governing rule is to load the smallest sufficient skill bundle for the current project, field, phase, task/domain, provider/runtime, tools, and policy context. Skills instruct; permissions and project policy authorize.

## Two-axis growth

TeamAi treats ToolKit growth as both:

- **Technical growth:** reusable skills, adapters, tools, and supported project/field types.
- **Operational growth:** better governance, continuity, evidence discipline, anti-pattern detection, reconciliation, responsibility allocation, and adaptation to project size and Agent count.

TeamAi is a consuming-project laboratory for testing whether a lesson survives real product execution. A lesson becomes a ToolKit candidate only after evidence, validation, and generalization show that it is reusable beyond TeamAi.

## Upstream / downstream boundary

```text
ToolKit
  → reusable process / skill
  → TeamAi WebAi seat
  → real execution + evidence
  → validated finding
  → generalized lesson
  → ToolKit
```

Project-specific TeamAi findings remain in TeamAi. ToolKit changes do not automatically alter TeamAi. Adoption must pass TeamAi Product Law, Policy, and endorsement discipline.
