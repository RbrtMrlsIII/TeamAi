# Skill: Semantic Transition Auditor

Status: GOVERNED EXECUTION SKILL / REAL

## Purpose

Determine whether a transition is semantically parameterized or merely visually generalized.

## Procedure

1. Identify canonical source and target semantic identities.
2. Identify source/target geometry and semantic ports.
3. Locate expansion and wiring ownership.
4. Trace subject derivation from the resulting geometry.
5. Verify camera target consumes the subject rather than static coordinates.
6. Re-run the same algorithm with a second valid source/target pair.
7. Reject the change if a new renderer branch is required for the second pair.

## Required evidence

- explicit transition object or equivalent canonical state;
- deterministic identity independent of coordinates/mesh labels;
- geometry mutation test;
- second-pair parameterization test;
- browser evidence for the assembled Hero when the gate requires runtime proof.

## Stop conditions

Stop promotion when identity is inferred from presentation state, camera presets become semantic owners, or the implementation needs pair-specific renderer logic.
