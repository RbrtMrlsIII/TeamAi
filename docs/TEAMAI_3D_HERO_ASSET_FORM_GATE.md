# TeamAi 3D Hero — Asset Form Gate

Status: planning/continuity only. Asset Function/Form/Runtime gates remain distinct; active TEAM-EXPERIENCE-029 implementation remains governed by `MASTERPLAN.md`.

## Asset family

The first additive authored family contains:

- `workspaceRing`: shared Web AI workspace spatial centerpiece.
- `seatShell`: reusable Web AI Seat station shell, instanced for 1–8 Seats.
- `contributionAnchor`: constrained Seat → shared workspace directional anchor.

## Form review

Before an authored asset is considered production-ready, verify:

- semantic silhouette is recognizable without text;
- symmetry and repeated instancing are deterministic;
- attachment and semantic-front axes are explicit;
- shell/recess/inset relationships read under grazing light;
- material boundaries support light-skeomorphic manufactured form;
- asset remains inside the Hero reserve and does not occlude the contribution corridor;
- semantic cameras preserve readable form at wide, team, seat-close, workspace-close, and turn-follow perspectives;
- 1–8 Seat scaling remains coherent without topology or spacing drift.

## Runtime review

Form approval does not imply Runtime approval. Runtime requires actual import/normalization, performance, camera/framing, interaction, responsive, reduced-motion, and browser evidence in the consuming Hero.

## Asset discipline

Assets are additive. Preserve the current authored `workspaceRing` / `seatShell` renderer path until an explicitly authorized replacement slice is implemented and verified. Reference geometry is not evidence of runtime fit.

No asset package may contain credentials, provider-private state, provider logos as authority signals, scheduler state, Firestore state, or authorization mutation behavior.
