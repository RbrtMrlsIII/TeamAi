## Census fidelity notice

The current Tree Census is **not a complete implementation census of the eventual 3D Hero world**.

It is a truthful structural/design baseline containing semantic tree families and branches that are currently defined or partially implemented. Undefined future trees, branches, sub-branches, and divisions have intentionally not been fabricated into the census.

A missing census entry means the semantic structure has not yet been authoritatively defined for this baseline. It does not mean the agent may invent a name, number, geometry, backend owner, or completion state.

The census must be updated when a semantic structure or its implementation is added, removed, renamed, materially restructured, or reimplemented. Partial implementation remains partial in the census.

## Legacy motion boundary

Existing prototype animations, camera movement, orbit behavior, transition choreography, effects, ambient motion, lighting responses, and timing values are **living implementation baselines only**.

They may be retained, refactored, replaced, or removed when the semantic machine requires different behavior. No existing prototype is allowed to become a hidden architectural dependency merely because it is already implemented.

The final tree/branch/division system is designed from semantic truth outward:

```text
semantic identity
→ responsibility
→ UI/product payload
→ division footprint
→ expansion clearance
→ connection topology
→ camera relationship
→ interaction states
→ animation/effects
→ verification
```

The reverse direction is prohibited:

```text
existing animation
→ force future tree geometry/topology to fit it
```

## Electrical and expansion independence

The future turn-loop electrical system must remain independent of prototype motion choices. Legacy camera docks, orbit timing, branch animation, and visual effect timing must not constrain:

- recursive tree/branch geometry;
- division-specific expansion space;
- adjacent-division clearance;
- connection corridor placement;
- semantic edge routing;
- active/open participating divisions;
- continuous tree-to-tree travel;
- workspace-center contribution flow.

Final electrical choreography begins from the actual connection graph and active division state, not from an existing visual effect.

## Command Deck relationship

The historical Command Deck is retired as a product/deployment surface. Its source and historical contracts may remain for reconstruction, but they do not constrain the spatial machine or become a renamed replacement surface.
