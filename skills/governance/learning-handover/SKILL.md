# Learning + Handover Skill

## WHEN TO USE
Use when an AI Development Team agent discovers a reusable lesson, improved procedure, warning, correction, or more efficient method during execution.

## INPUT
Observed lesson, execution evidence, affected Masterplan item, applicable ORUCAVEAM letter(s), affected field/domain skill or document, scope, limitations, and whether the lesson appears TeamAi-specific or generalizable.

## AUTHORITY
`POLICY.md` defines execution discipline and endorsement scope. `PRODUCT_LAW.md` remains product authority. `AI_ASSISTANT_READ_ME.md` owns live continuation/recovery state; `docs/project-guide/Endorsement.md` records authorized acceptance.

## ACTION
1. Record what was discovered and why it matters.
2. Tie the lesson to the executed Masterplan checklist, applicable ORUCAVEAM letter skill(s), field/domain skill(s), and evidence.
3. If the lesson concerns UI surfaces, state whether it affects legal boxes or only F0–F7 field identity.
4. Put current continuation/recovery state in `AI_ASSISTANT_READ_ME.md`.
5. Record exact acceptance in `docs/project-guide/Endorsement.md` only when the acceptance boundary is actually authorized and evidenced.
6. Update the appropriate operational skill when the procedure itself changed.
7. Update `AI_ASSISTANT_READ_ME.md` when the lesson is a practical session/recovery technique.
8. Update `PRODUCT-KNOWLEDGE.md` only when the lesson is validated and worth permanent retention.
9. Propose a ToolKit upstream candidate only after the lesson has enough evidence and scope analysis to test for generalization.
10. Preserve historical handover records under `docs/archive/` when they are no longer active.

## DO NOT
- Promote an agent opinion directly to Product Law.
- Call a lesson generalized because it worked once.
- Store raw conversation or screenshot evidence in Product Knowledge.
- Change a skill without checking the governing Product Law, Masterplan, and Policy.
- Hide a changed procedure in a canonical document when it belongs in a reusable skill.
- Quietly promote F6 Status or F7 Modal into legal boxes through session/recovery wording.
- Create a second live handover manual.
- Revive `docs/project-guide/HandOver.md` as an active path.

## PASS
The lesson has an evidence path, a clear scope, an identified Masterplan item, applicable ORUCAVEAM/field skill destination, and a durable current-session/acceptance path where required.

## EVIDENCE
Execution result, Masterplan item, source/skill path, ORUCAVEAM letter(s), verification result, `AI_ASSISTANT_READ_ME.md` state when applicable, endorsement state when applicable, and Product Knowledge row if promoted.
