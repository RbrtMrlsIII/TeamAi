# Machine Hero Frontend Builder

## WHEN TO USE
Use when creating or reworking a 3D Hero machine surface, semantic transition, subject footprint, camera relationship, or renderer-neutral spatial prototype.

## AUTHORITY
Product Law and the governed Machine Hero qualification law are authoritative. `MASTERPLAN.md` owns chronology. The tree census owns semantic tree/branch/division inventory. This skill may not invent missing product semantics.

## ACTION
1. Recover the current semantic tree/branch/division identity and implementation owner.
2. Build a canonical transition object from semantic identity, geometry, ports, expansion, wiring, and subject.
3. Derive the subject footprint from geometry. Never derive subject identity from camera coordinates.
4. Keep camera identity/configuration separate from semantic target/subject.
5. Prefer renderer-neutral state modules before renderer-specific code.
6. Build responsive and reduced-motion behavior into the contract, not as a later cosmetic patch.
7. Add deterministic unit coverage for geometry mutation and at least one alternate valid semantic pair using the same renderer algorithm.
8. For visual prototypes, keep production activation opt-in until the governed promotion gates permit migration.
9. Reconcile census representations only when tree/branch/division semantics, payload, or structural ownership actually changes. Renderer-neutral proof modules use the presentation-only evidence boundary.
10. Keep backend, entitlement, authorization, scheduler, and provider authority outside the Hero renderer.

## DO NOT
- Do not copy static camera coordinates as semantic identity.
- Do not create a second production WebGL runtime merely to prototype a state.
- Do not animate disconnected electrical paths.
- Do not make a screenshot or green CI result into product acceptance.
- Do not fabricate tree/branch IDs, payloads, provider state, or durable domain state.
- Do not weaken governance validators to make the implementation green.

## PASS
The slice passes this skill only when the semantic transition is deterministic, geometry-derived subject behavior is tested, camera identity remains independent from subject targeting, production authority boundaries are intact, and the appropriate truth/evidence record is updated.
